## Post-review bugfix (2026-07-22)

**Issue:** `getStrategyDossier` line 105 used `.map((c) => c.id!).filter(Boolean)`, which drops `id === 0` (valid but falsy) and relies on non-null assertion despite the type being optional.

**Change to `src/lib/screening.ts` line 105:**
```typescript
// Before:
const ids = (campaigns ?? []).map((c: ScreeningCampaign) => c.id!).filter(Boolean)

// After:
const ids = (campaigns ?? [])
  .map((c: ScreeningCampaign) => c.id)
  .filter((id): id is number => id != null)
```

**Rationale:** Type guard `(id): id is number => id != null` filters only `null`/`undefined`, preserves `0`, and narrows the type without assertion.

**Verification:**
- `npx tsc --noEmit` → no output (no errors)
- `npx vitest run --dir tests tests/lib/screening.test.ts` → 10 passed (1)

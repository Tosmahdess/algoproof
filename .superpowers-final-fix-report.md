## C1 — wrong denominator, ~5x error, inverted argument

- Added `n_assets: number | null` to `ScreeningCampaign` in `src/lib/screening.ts` (free — migration hasn't run).
- `src/components/ScreeningDossier.tsx`: `assetsExhibitParagraph` now takes `nAssets` and computes density as
  `(a.trades + b.trades) / (2 * nAssets)`, omitting the whole density clause when `nAssets` is null/0.
- `tests/components/ScreeningDossier.test.tsx`: fixture now carries `n_assets: 30`; the previously-pinned-wrong
  `environ 39 trades par actif` assertion is replaced with the correct `environ 8` (470/60 → 7.83 → 8), plus an
  explicit test that the clause disappears when `n_assets` is null.

## C2 — flagship exhibit rendering on empty lists

- Gate changed from `candidates.length === 2` to also requiring both candidates'
  `qualified_assets.length > 0` (`showAssetsExhibit` in `ScreeningDossier.tsx`).
- Test added: both candidates with `qualified_assets: []` → exhibit absent.

## C3 — zero-candidate prose keyed off the wrong thing

- Branch now keys on `campaign.n_candidates === 0` (not `candidates.length === 0`).
- New middle branch: `n_candidates > 0 && candidates.length === 0` → explicit "Détail indisponible" paragraph.
- Tests added for both: a stray candidate row leaking through a zero-candidate campaign still reads as a result,
  and a campaign claiming candidates but shipping none renders the new indisponible state (not the funnel
  contradiction, not silence).

## I1 — family route dies when tables are missing

- `getScreeningGrid` and `getStrategyDossier` in `src/lib/screening.ts` now `console.error` + degrade instead of
  throwing, matching `getProvenanceForBot`'s existing pattern:
  - `getScreeningGrid` → `[]`
  - `getStrategyDossier` → `{ campaigns: [], candidates: {}, events: [] }` (wrapped in try/catch, with each of the
    three internal fetches — campaigns, candidates, events — checked individually)
- `mockChain` helper in `tests/lib/screening.test.ts` extended with `.in()` to support the candidates-fetch path.
- Tests added covering: success path, campaigns-fetch failure, candidates-fetch failure, events-fetch failure
  (all asserting the labeled `console.error` call and the empty-result return).

## I2 — asserts bots that may not exist

- `assetsExhibitParagraph`'s closing clause now derives bot count from
  `[a, b].filter(c => c.bot_slug !== null).length`: 0 → "la sélection d'actifs attend les données à venir"; 1 →
  singular "le bot en observation trade…"; 2 → original "les deux bots en observation tradent…".
- Tests added for the 0-bot fallback and the 1-bot singular case.

## I3 — funnel does not sum

- `ScreeningDossier.tsx` computes `residual = n_behaviors - (n_rejected + n_marginal + n_candidates)` only when
  all four are non-null, and renders an extra `├─ {residual} configurations comptabilisées ailleurs` tree line
  when `residual !== 0`.
- Test with the real numbers (73 770 / 73 744 / 20 / 2 → residual 4) asserts the line appears; a second test with
  exactly-summing numbers asserts it's omitted.

## I4 — null count rendered as a confident zero

- `ScreeningGrid.tsx`: cell now renders `—` unless `state === 'judged' && n_candidates !== null` (previously
  `String(c.n_candidates ?? 0)` masked null as `'0'`).
- `cellLabel` in `screening.ts`: judged campaign with `n_candidates === null` → bare `'clos'`, distinct from the
  `'clos · résultat négatif'` used for an actual zero.
- Tests added at both layers (unit test on `cellLabel`, component test on the grid cell + state column).

## I6 — raw ISO dates on a French site

- Added exported `frDate(d: string | null): string` to `src/lib/screening.ts` using the noon-UTC anchor
  (`new Date(d + 'T12:00:00Z')`) already used elsewhere in the codebase, formatted via
  `toLocaleDateString('fr-FR', { day: '2-digit', month: '2-digit', year: 'numeric' })`; returns `'—'` for null.
- Applied at all four sites: `ScreeningDossier.tsx` (header), `BotProvenance.tsx` (closing sentence),
  `ScreeningGrid.tsx` (state column), `src/app/strategies/famille/[base]/page.tsx` (journal des verdicts).
- Unit tests added for `frDate` (normal date, a date near a month boundary, and null); component tests assert
  the French format renders and the raw ISO string does not.

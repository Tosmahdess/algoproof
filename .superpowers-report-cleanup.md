# Cleanup report — screening dashboard moved to the lab

Branch: `feat/screening-move-to-lab` · Repo: `D:\code\algoproof`

## What was removed

1. **`/strategies` coverage grid** (`src/app/strategies/page.tsx`): removed the
   `getScreeningGrid` fetch, the `ScreeningGrid` import, and the `<section>` rendering it. Page
   now fetches only `getAllBotsWithStats()`, as it was before the grid was added. No unused
   imports, no empty `Promise.all` left (the `Promise.all([...])` itself was removed since there
   is now only a single fetch).

2. **`src/app/strategies/famille/[base]/` route**: deleted entirely (`page.tsx`, 68 lines). The
   dossiers now live at `lab.algoproof.fr/moteur-backtest/[base]`.

3. **`next.config.ts`**: added a permanent redirect
   `{ source: '/strategies/famille/:base', destination: 'https://lab.algoproof.fr/moteur-backtest/:base', permanent: true }`
   to the existing `redirects()` block (which already existed, alongside the `/wealth/analyses`
   and blog-journal redirects) — the old path was live and deployed, so it must not 404.

4. **`src/components/ScreeningGrid.tsx`**, **`src/components/ScreeningDossier.tsx`**, and their
   test files (`tests/components/ScreeningGrid.test.tsx`,
   `tests/components/ScreeningDossier.test.tsx`) — deleted. They now live in the algolab repo.

5. **`src/lib/screening.ts`** trimmed from 289 to 130 lines. Kept (verified as what
   `BotProvenance.tsx` actually imports): `ScreeningCampaign` type, `ScreeningCandidate` type,
   `ScreeningState` type (kept because `ScreeningCampaign.state` is typed with it — not itself
   imported by name elsewhere, but required for the surviving type to compile), `fr` (private
   helper used by `marginLabel`), `frDate`, `count`, `marginLabel`, `getProvenanceForBot`.
   Deleted, after confirming each was referenced only by files removed in this same change:
   `getScreeningGrid`, `getStrategyDossier`, `cellLabel`, `corpusTotals` (+ its `CorpusTotals`
   type), `crossTf` (+ its `CrossTf` type), `TF_ORDER`, `isDossierUnlocked`, `ScreeningEvent` type,
   and the internal `EMPTY_DOSSIER` constant.
   `tests/lib/screening.test.ts` trimmed in lockstep — kept the `marginLabel`, `count`, `frDate`,
   `getProvenanceForBot` describe blocks; dropped `TF_ORDER`, `cellLabel`, `isDossierUnlocked`,
   `getScreeningGrid`, `getStrategyDossier`, `corpusTotals`, `crossTf` describe blocks.

   One gotcha worth flagging: while retyping the `count()` function and its test's
   `NARROW_NBSP`/`ASCII_SPACE` constants by hand, I twice introduced raw Unicode NBSP/NNBSP
   *characters* into the regex/replacement literal instead of preserving the original's literal
   6-character escape sequences (` `, ` `) — the exact class of bug this code's own
   comments warn about. Caught it by inspecting the file's raw bytes (`cat -A` / Python `repr()`)
   before committing, and rewrote the file so both the escape-sequence lines (`count()`'s regex)
   and the intentional-literal-character lines (the test's `NARROW_NBSP` fixture, which the
   comment explicitly says must hold the real byte) ended up byte-identical to the pre-change
   file — confirmed via `git diff` showing those specific lines as unchanged.

6. **`BotProvenance.tsx`** link retargeted: was `<Link href={`/strategies/famille/${campaign.base}`}>` (next/link, same-site),
   now a plain cross-site `<a href={`https://lab.algoproof.fr/moteur-backtest/${campaign.base}`} target="_blank" rel="noopener noreferrer">`.
   Used `rel="noopener noreferrer"` rather than the brief's literal `rel="noopener"` — the repo's
   actual convention for `lab.algoproof.fr` links opened in a new tab
   (`src/app/intelligence/page.tsx:127`, `src/app/strategies/[slug]/page.tsx:137-140`) is
   consistently `noopener noreferrer`, and the brief itself said to follow that convention.
   `tests/components/BotProvenance.test.tsx`: the "links back to the dossier" test now asserts
   the new `href`, plus `target="_blank"` and `rel="noopener noreferrer"`.
